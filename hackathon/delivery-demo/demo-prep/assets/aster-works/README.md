# Aster Works — logo SVG

- [Pełne logo](aster-works-logo.svg) — pionowy układ znaku i napisu.
- [Sygnet](aster-works-symbol.svg) — ten sam znak wyodrębniony kadrem SVG.
- [Napis](aster-works-wordmark.svg) — liternictwo wyodrębnione kadrem SVG.
- [Podgląd](preview.html) — otworzyć lokalnie w przeglądarce.

Wersja naprawcza po odrzuceniu pierwszego, przeprojektowanego logo. Tamten zestaw
nie jest materiałem do wdrożenia. Obecny SVG jest wektoryzacją oczyszczonej,
odtworzonej wersji dostarczonego obrazu: zachowuje charakterystyczny układ i masywne
liternictwo zamiast zastępować je zwykłym fontem lub cienkim symbolem sieci.

Proces: oczyszczenie narzędziem obrazowym, redukcja do trzech kolorów, wektoryzacja
konturów i kontrola renderowania. To rekonstrukcja, nie oryginalne krzywe autora
ani gwarancja identyczności pikselowej. Oczyszczenie mogło zmienić drobne granice
ciemnych elementów; porównanie z dostarczonym wzorem pozostaje istotne.

Pliki zawierają rzeczywiste ścieżki SVG, bez rastrowego obrazu, fontów, skryptów,
zewnętrznych odwołań i poświaty. Tło oraz negatywowe przestrzenie są przezroczyste.
Odmiany sygnet/napis mają własny viewBox; nie są nowym projektem znaku.

Paleta: granat #082C55, niebieski #0757B8, cyjan #12B8DB. Główna wersja przeznaczona
na jasne tło. Nie umieszczać granatowego napisu bezpośrednio na ciemnym hero;
użyć jasnego pola pod logo. Odmiana o jasnym napisie wymaga osobnego przygotowania.
Nie rozciągać proporcji ani nakładać poświaty w nawigacji. Przed użyciem sygnetu
jako favicony sprawdzić czytelność w16/32px; duży znak nie gwarantuje czytelności tam.
